Proyek Utama • Web Development

Situs Web E-Commerce Dinamis Berbasis PHP

Aplikasi web belanja dinamis yang dirancang untuk mengelola penyajian katalog produk dan pemrosesan alur data transaksi di sisi server.

Tantangan:

Kebutuhan platform web toko online yang dapat memproses transaksi dan menampilkan katalog secara otomatis tanpa pembaruan manual halaman statis.

Solusi & Alur Kerja:

Membangun arsitektur web berbasis PHP di Visual Studio Code untuk mengelola alur logika pemesanan serta menyajikan tampilan antarmuka katalog produk secara dinamis.

Fitur Utama (Features):

Katalog produk dinamis, keranjang belanja (shopping cart), alur checkout pemesanan, dan konfirmasi pembayaran.

Peran & Kontribusi:

Menulis skrip PHP untuk logika sisi server (server-side logic), pemrosesan data keranjang dan checkout, serta integrasi alur transaksi.

Proyek Pendukung • Networking

Implementasi & Konfigurasi Jaringan Lokal (LAN)

Pembangunan infrastruktur jaringan kabel area lokal (LAN) untuk menghubungkan beberapa komputer ke jaringan internet secara stabil dan teratur.

Tantangan:

Membangun jalur transmisi data fisik yang bebas interferensi serta memiliki skema pengalamatan IP yang terisolasi dan mudah dilacak.

Solusi & Alur Kerja:

Merakit kabel UTP secara mandiri menggunakan konektor RJ45, menghubungkan ke Switch/Hub, dan menerapkan konfigurasi IPv4 Statis pada setiap host.

Peran & Kontribusi:

Memotong dan melakukan crimping pin kabel UTP, menguji integritas transmisi fisik, mengatur alamat IP Statis, Subnet Mask, serta menguji konektivitas ping.

Kabel UTP RJ-45 Crimping Switch / Hub IPv4 Static LAN Network
